# Minimalist To-Do List

A modern, distraction-free To-Do List application built with **React** and **Vite**, featuring a clean **Minimalist Monochrome & Graphite** aesthetic, task prioritization, inline editing, and filtering controls.

---

## ✨ Features

- **Task Management**: Create, mark as complete, edit, and delete tasks seamlessly.
- **Priority System**: Assign priority levels (P1, P2, P3, etc.) to tasks with subtle, color-coded badges.
- **Inline Editing**: Quick inline editing for task names and priorities without modal interruptions.
- **Filtering & Sorting**:
  - Toggle to filter between all tasks and only incomplete tasks.
  - Sort tasks by priority with a single click.
- **Progress Tracking**: Real-time task counter displaying total and completed tasks.
- **Minimalist Aesthetic**: Distraction-free, dark monochrome palette with refined typography, frosted glass surfaces, and smooth micro-animations.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

---

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS (Custom Design System with CSS Variables)
